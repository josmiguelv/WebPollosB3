## Logo proporcionado por el usuario

El usuario adjuntó el logo oficial como PNG RGBA. El original permanece sin modificar en la entrada recibida. Para la cabecera se genera una copia con el margen exterior de transparencia prácticamente nula recortado; no se alteran los píxeles visibles del logotipo. El rojo `#FE1601` es el valor RGB exacto más frecuente entre los píxeles rojos opacos del arte; el archivo conserva sus gradientes rojos originales.

## Decisiones para esta base visual

Las publicaciones consultadas contienen información comercial que no coincide entre sí; no se eligieron como fuente de precios ni como catálogo vigente. No se han copiado al sitio nombres de productos, precios, promociones ni disponibilidad de esas imágenes. Tampoco se ha descargado ni embebido en la web ninguna fotografía o composición comercial de Pollos B3.

La imagen pública del perfil de Facebook revisada no es un archivo independiente y utilizable del logotipo. Por ello, el arte de la web procede del adjunto del usuario, no de una copia de red social. El recurso oficial de marca está integrado en el encabezado y sus metadatos de proyecto.

Las redes se muestran únicamente como enlaces a los canales identificados; no se usan como una fuente automática para datos comerciales. Las fotografías/videos oficiales de producto, precios e información operativa seguirán pendientes hasta que Pollos B3 proporcione los activos correspondientes y autorice las fuentes de datos.
